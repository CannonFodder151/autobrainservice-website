Host it yourself — free

AutoBrain is MIT-licensed and ships as a complete Docker Compose stack: backend, AI gateway, worker, Postgres, Redis and MinIO behind a single nginx entry point. Four vCPUs and 8 GB of RAM is plenty.

  1. Get the source — clone the public repository and copy the environment template: 
    git clone https://github.com/CannonFodder151/autobrain.git
cd autobrain
cp .env.example .env
  2. Set your AI router — point AI_ROUTER_URL at any OpenAI-compatible router. No router? The built-in rule-based fallbacks keep everything working offline.
  3. Bring it up: 
    docker compose -f docker-compose.prod.yml up -d --build
  4. Log in — the bootstrap admin is created from ADMIN_EMAIL / ADMIN_INITIAL_PASSWORD in .env. Create accounts for your users; there is no self sign-up.
  5. Protect it — enable TOTP MFA in Settings & security, set a strong SECRET_KEY, and rotate the admin password.

Full deployment, backup and Kubernetes guidance is in the repo docs — or ask us and we'll help you set it up.
