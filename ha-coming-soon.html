What's changing

The migration is transparent to users. Everything underneath moves to Oracle Cloud Infrastructure, but your AutoBrain experience stays exactly the same — and gets more reliable.

Architecture

OCI multi-zone

AutoBrain Hosted moves from a single-zone deployment to Oracle Cloud Infrastructure with primary + standby across two availability domains. Single-zone failure no longer takes you offline.

Deployment

Rolling updates

Zero-downtime rolling deployments replace the old one-shot deploy. Updates ship incrementally with health checks at each stage. If something looks wrong, the rollout pauses — no impact on users.

Resilience

Automatic failover

Load balancer health checks every 30 seconds. If the primary zone fails, traffic reroutes to the standby within 60 seconds. No manual failover button, no waiting for a human to respond at 2 AM.

Self-hosted AutoBrain stays on the same self-host path. The HA migration applies only to the managed hosted service — your self-hosted deployment continues to run on the infrastructure you control. Self-hosting guide →

HA Migration FAQ

Will there be any downtime?

No. The migration uses a phased cutover with redundant capacity. You stay logged in and working throughout — the standby zone is live and serving traffic before the primary zone transitions.

Do I need to update my app or settings?

No. The mobile app and web app continue to work exactly as before. No new app version or configuration is required — the DNS transition is seamless for existing connections.

Is my data safe during the migration?

Yes. All data is encrypted in transit (TLS 1.3) and at rest (AES-256). The migration copies data to the new OCI region with per-record verification before the cutover begins. Nothing is lost or corrupted in the process.

Will the pricing change?

No. All existing plans and prices remain the same — Free, Enthusiast ($5.90/mo or $59/yr), and Garage ($11.90/mo or $119/yr). The HA architecture is included at no extra cost.

What if I self-host AutoBrain?

Self-hosted AutoBrain is unaffected. The HA migration applies only to the managed AutoBrain Hosted service. Your self-hosted deployment stays exactly as it is — no changes needed on your end.

When exactly will this happen?

Targeted for mid-October 2026. We'll post updates on the public changelog and the AutoBrain #changelog channel as each phase completes. Sign up below to get notified directly.
