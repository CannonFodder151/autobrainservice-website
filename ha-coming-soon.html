Rollout FAQ

When does the Home Assistant integration ship?

Targeted for Q4 2026, starting with the Phase 1 REST + WebSocket feed (sensors and service-interval calendar entries) and followed by the HACS custom integration in Phase 2. Watch the public changelog and the AutoBrain #changelog channel for the day each phase lands.

What data does AutoBrain actually push to Home Assistant?

Only processed insights you opt in to — current rego status and expiry, upcoming service intervals, AI maintenance predictions, fuel efficiency and cost trends, and EV charge-session summaries. Raw OBD2 PIDs, live telemetry and GPS routes never leave AutoBrain unless you explicitly surface them.

Will I need new hardware?

No. The integration runs on the same AutoBrain backend you already use — hosted or self-hosted. Phase 2 adds an optional HACS custom integration for one-click setup inside Home Assistant.

Which plans include the Home Assistant integration?

The Home Assistant integration is included in every AutoBrain plan — Free, Enthusiast and Garage — and is available to self-hosters too.
