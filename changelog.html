v0.3.3

2026-08-06

Added

  • Vehicle type: every vehicle is a Car or a Motorcycle (dropdown on add/edit). The home screen shows a motorcycle icon for bikes, and the vehicle type is passed to the AI agents (diagnostics, service prediction, valuation, mod impact).
  • Admin console: search users by display name or email — alphabetical, 15 per page, with previous/next buttons.
  • Account creation (signup + admin) rejects duplicate emails and duplicate display names.
  • "Delete account" menu item for non-admin users on licensed servers, linking to the deletion instructions page.
  • Demo data: two motorcycles plus logbook trips, scanned receipts, valuations and diagnostics.

Fixed

  • Service/mod photo_keys now store as JSON (raw-list inserts previously failed).
  • Web home screen no longer shows garbled characters on the vehicle display.
  • Admin user list no longer 500s — UserAdminOut now serializes ORM rows (blank list / broken search fixed).
  • CSV exports include a UTF-8 BOM so Excel renders em-dashes and unicode correctly instead of garbled characters.
  • Home screen shows a clear "server unreachable" error (with Retry) instead of "no vehicles" when the backend is offline.

v0.3.2

2026-08-06

Changed

  • Android app distributed via Google Play (com.autobrainservice.app); the in-app "Get the mobile app" download dialog and menu item are removed.
  • Mobile: sign out now offers "Sign out & change server"; new app icon.
  • Rego lookup resilience: provider timeout raised to 90s (covers the scraper's fast-fail + retry).

v0.3.1

2026-08-06

Fixed

  • Fuel efficiency (L/100km, cost/km) now calculates when you back-fill an older fill-up. The full-tank efficiency chain is recomputed after every add/edit/delete; out-of-order or duplicate odometer entries stay blank instead of getting a wrong value.

v0.3.0

2026-08-06

Added

  • Fuel tracker: filter by Australian financial year, and export by FY as CSV or CSV + receipt images (ZIP). Scanned receipts are saved against the fuel record and exported alongside it.
  • Service history and build sheet exports support fmt=zip: CSV gains an Image column and the receipt/scan photos are bundled in the ZIP.
  • Receipt scans auto-attach their image to the service record created from the scanner.
  • Admin console: "Re-upgrade" grants the $19/month benefits without a Stripe subscription; sponsored accounts are blocked from buying a licence.
  • Licence/upgrade feature gated behind LICENSE_ENABLED — on for the hosted instance, off for demo/default and self-hosted.
  • Self-hosted rego lookup: REGO_LOOKUP_URL points at the Plate-API-Scraper instead of the paid provider.

Fixed

  • Fuel receipts no longer stay stuck on "pending" when OCR is unavailable.
  • Removed the odometer photo-scan option from the logbook.

v0.2.4

  • SELF_SIGNUP_ENABLED drives the UI: the app hides the "Create a free account" button when disabled (hosted keeps signup on; demo/default off).

v0.2.0

2026-08-05

Added

  • Vehicle colour field with rego-lookup auto-fill.
  • Self-service Free-tier signup (hosted) with a 7-day setup email (password + MFA).
  • Stripe self-service billing: Checkout, Customer Portal, cancel-at-end-of-period, webhook promote/demote.
  • OBD2 hardware companion listed as Coming soon on the marketing site.
  • ATO logbook: per-trip logging, GPS, work/private, financial-year CSV export, dashboard-photo odometer OCR.
  • Club registration selector (club-reg vehicles disable the logbook).
  • Fuel: edit/delete fill-ups, fuel-receipt photo upload (AI parse), per-FY CSV export; fuel updates the odometer.
  • Free account tier: disables AI + rego lookup; exports available on all plans.
  • Server version in admin settings with GitHub release check.
  • Diagnostics: resolve/delete; auto-resolves when its scheduled service completes.
  • Profile export/import (full JSON account).
  • Admin backup & restore + scheduled daily backup (Celery beat → MinIO) with retention.
  • Admin API key (ADMIN_API_KEY): machine-to-machine user management.
  • OBD-II seam: fault-code library, VIN auto-fill, admin-gated access, Bluetooth auto-connect.
  • AI gateway: fuel-ocr and odometer modules; temperature 0, clamped numeric output.
  • Live 9Router integration (OpenAI-compatible router client).
  • Flutter web build served at / behind the proxy nginx.
  • TOTP MFA + self-service password reset; role-based access with admin user management.
  • Australian rego lookup (state-aware, word decoding, optional provider).
  • Services overhaul: scheduled/completed status, items + work steps, AI prediction, PDF/CSV export.
  • Receipt & parts OCR, parts inventory with AI reorders, resale estimator, analytics.

Fixed

  • Login/MFA focus and Enter-to-submit fixes; MFA setup busy-state cleared.

Changed

  • Free accounts can export files; only AI and rego lookup remain paid. MFA available on all tiers.

Removed

  • GitHub Actions CI/CD workflows; the initial scaffold.
