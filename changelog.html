Changelog

Every release of AutoBrain — new features, fixes and improvements. Also tracked in the repo's CHANGELOG.md.

v0.3.1

2026-08-06

Fixed

  • Fuel efficiency (L/100km) now calculates even when you back-fill an older fill-up — the whole full-tank chain is recomputed after every add/edit/delete, and out-of-order odometer entries no longer corrupt the numbers.

v0.3.0

2026-08-06

Added

  • Fuel tracker: filter by Australian financial year and export by FY as CSV or CSV + receipt images (ZIP). Scanned receipts are saved against the fuel record and exported with it.
  • Service history and build sheet exports can bundle the images as a ZIP, with an Image column referencing each file.
  • Receipt scans auto-attach their image to the service record created via the scanner.
  • Admin console: "Re-upgrade" option grants the $19/month benefits to an account without a Stripe subscription, and blocks the user from buying a licence.
  • Licence/upgrade page is now feature-flagged (LICENSE_ENABLED) — on for the hosted service, off for self-hosted and demo.

Fixed

  • Fuel receipts no longer stay stuck on "pending" when OCR is unavailable.
  • Removed the odometer photo-scan option from the logbook.
  • Rego lookup now uses the self-hosted Australian plate scraper instead of the paid provider, with the offline heuristic as fallback.

v0.2.4

2026-08-05
  • Self-service signup flag now drives the UI — the "Create a free account" button is hidden when signup is disabled.

v0.2.3

2026-08-05
  • Receipt MIME detection fixes.

v0.2.0

2026-08-04
  • Vehicle colour and body type fields, with rego-lookup auto-fill.
  • Free account tier (disables AI and rego lookup).
  • Australian rego lookup with offline heuristic fallback.
  • Vehicle management, multiple profiles, unified timeline.
