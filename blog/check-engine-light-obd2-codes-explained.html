Check Engine Light On? OBD2 Codes Explained

AutoBrain Team · 9 October 2026 · Diagnostics

A warning light is your engine computer telling you it stored a fault. Here is how to find out which one, whether it is safe to drive, and what the common Australian codes actually cost to fix.

What does the check engine light mean?

The check engine light (CEL) is not a breakdown warning — it is a stored fault code. Every car built since 2006 in Australia has an OBD2 port, and the engine computer writes a diagnostic trouble code whenever a sensor reading goes out of range. The light is the visible symptom; the code is the actual diagnosis.

That distinction matters. A workshop that clears the light without reading the code has thrown away the evidence. Read the code first — it usually tells you which system to look at before anyone opens the bonnet. Our car diagnostics guide covers the background on how the ECU decides to light up.

Is it safe to drive with the check engine light on?

  • Steady light — the fault is not immediately dangerous. You can usually drive to a workshop, but don't leave it for months: a misfire or a lean mixture left untreated can damage the catalytic converter.
  • Flashing light — active misfire. Pull over safely, switch the engine off and get it towed if you have to. Driving on a flashing light can wreck a catalytic converter and turn a small repair into a large one.
  • Light plus rough running, power loss or a burning smell — stop driving and book a workshop.

If the light appears during a NSW or Victorian roadworthy inspection window, expect it to be photographed. Clear the fault before the inspection, not after.

What are the most common OBD2 codes Australian drivers see?

The codes Australian drivers hit most often are P0300 (random misfire), P0420 (catalyst efficiency below threshold), P0171 (system too lean), P0440 (evaporative emissions) and P0128 (coolant thermostat). OBD2 code meanings & repair costs 2026 lists each one with likely causes and Australian price ranges.

The pattern behind them is the useful part:

  • P0440 / P0455 — often a loose fuel cap or a cracked emissions hose. The cheapest codes in the list.
  • P0171 — a vacuum leak, a dirty air flow sensor or a tired fuel pump. Common on older cars with high kilometres.
  • P0300 — worn spark plugs or failing ignition coils. Frequent on cars that have never had a full service history.
  • P0128 — a stuck-open thermostat. Cheap to fix if caught early, overheating damage if ignored.

How do I read the code myself?

  1. Plug in an ELM327 adapter (about $15–$40) to your car's OBD2 port — usually under the steering column.
  2. Pair it with your phone over Bluetooth or USB.
  3. Open AutoBrain and scan. The AutoBrain OBD2 adapter plugs in once and keeps logging while you drive.
  4. Read the plain-English meaning, severity and typical Australian repair cost — not just a code number.

Will the light come back if I just clear the code?

Yes — if the fault is still there. Clearing a code resets the readiness monitors; it changes nothing about the car. Clear it after the repair, then drive a few cycles. If the light returns, the fault is still active and you have a second, cheaper diagnostic clue: the code that comes back first.

And if the car was already hard to start before the light appeared, read car won't start — the common causes before paying for a battery.

When is a mechanic worth it?

Scan it yourself first if you own a Bluetooth OBD2 adapter. Book a workshop when the code is emissions-related (P04xx), when multiple codes appear at once, when the light flashes, when the car is due an inspection, or when you've cleared a code twice and it's back. The scan tells you whether you're dealing with a $12 hose or a $2,000 converter.

Frequently asked questions

Is it safe to drive with the check engine light on?

A steady light usually means a fault that isn't immediately dangerous, so you can drive to a workshop. A flashing light means an active misfire — stop driving, because it can destroy the catalytic converter.

What does a check engine light code tell you?

OBD2 codes are the diagnostic trouble codes the engine computer stored: P0300 random misfire, P0420 catalytic converter efficiency, P0171 lean mixture, P0440 evaporative emissions, P0128 thermostat. The code narrows down which system to check.

How much does it cost to fix a check engine light code in Australia?

From under $100 for a fuel cap or emissions hose, to $150–$400 for a thermostat, $250–$600 for an oxygen sensor, and $1,000–$2,500 for a catalytic converter. Read the code first so the workshop quotes a diagnosis rather than a guess.

Will the light come back if I clear the code?

Yes, if the underlying fault is still active. Fix or diagnose first, then clear, then drive a few drive cycles to confirm the light stays off.

Do I need an adapter to read codes myself?

You need an ELM327 Bluetooth or USB adapter (about $15–$40) and a phone app. AutoBrain reads the codes over it and explains each one with Australian repair cost ranges.
